Download for Mac

Free and open source. Requires macOS 26 or later. Available in 11 languages.

Black menu bar

The menu bar turns black, so the notch blends in. Turn it on and off from the menu bar.

Rounded screen corners

Rounded corners make the screen look like one clean shape. Turn them off if you only want the black bar.

External displays too

Use the same look on displays without a notch, so all your screens match.

Stays out of the way

No Dock icon. Start it at login, or hide the menu bar icon completely.

Install

  1. 1

    Download the latest HideNotch.dmg from GitHub.

  2. 2

    Open it and drag HideNotch into Applications.

  3. 3

    Launch it. HideNotch lives in the menu bar, click the icon to open its settings.

Or install it with Homebrew:

brew install --cask niklasravnsborg/tap/hidenotch
